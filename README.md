# UMC 8th Web 워크북 실습 (2025.03 ~ 2025.06)

## 개요
UMC 8기 Web 파트 활동 중 진행된 워크북 실습 과제를 정리한 레포지토리입니다.  
React, TypeScript, Tailwind CSS 등을 활용하여 단계별 과제를 수행하며 실무형 프로젝트 경험을 쌓는 것을 목표로 했습니다.

---

## 디렉토리 구조
```
.
├── mission1/   # 1주차~3주차 실습: 기본 React 컴포넌트, 상태 관리
├── mission2/   # 4주차~6주차 실습: Router, 비동기 통신, API 연동
├── mission3/   # 7주차~9주차 실습: TanStack Query, Infinite Scroll
├── mission4/   # 10주차~12주차 실습: 성능 최적화(useMemo, useCallback 등)
└── README.md
```

---

## 사용 기술 스택
- **Frontend**: React, TypeScript  
- **스타일링**: Tailwind CSS  
- **상태 관리**: Zustand, TanStack Query  
- **빌드 도구**: Vite  
- **기타**: ESLint, Prettier

---

## 학습 목표
1. React 컴포넌트와 상태 관리 기초 학습
2. Router와 API 연동을 통한 SPA 구조 이해
3. TanStack Query를 활용한 비동기 데이터 관리 및 무한 스크롤 구현
4. 성능 최적화(useMemo, useCallback, React.memo) 실습
5. 프로젝트 구조화 및 협업 경험 축적

---

## 실행 방법
```bash
# 패키지 설치
yarn install

# 개발 서버 실행
yarn dev

# 빌드
yarn build
```

## 회고
- **성장 포인트**: 단순히 기능 구현이 아닌, 재사용성과 유지보수를 고려한 코드 작성 습관을 배웠습니다.  
- **어려웠던 점**: 상태 관리와 비동기 처리의 타이밍 이슈 → TanStack Query와 Zustand를 통해 개선했습니다.  
- **성과**: UMC 활동을 통해 팀 프로젝트와 개인 과제를 병행하며, 실무형 풀스택 역량을 한층 더 끌어올릴 수 있었습니다.
